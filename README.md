# Mr. Movies

Next.js (App Router) + TypeScript + Tailwind starter.

A basic set up allowing the user to view the first page (API limited to one page ) of the most popular films (The API is sorted from post popular) films of 2025 (API is limited to 2025).

Users can sort by title, release date, or average rating as well as filter via the text input in the top-right of the navigation bar.

Note: Please set the TMDB key to TMDB_API_KEY in env.local to connect to the API.

```bash
npm i && npm start
```

Then open [http://localhost:3000](http://localhost:3000).
